# NASA Plant Space Omics

Reproducible analysis of publicly available NASA OSDR/GeneLab plant omics datasets.

## Research focus

Comparative analysis of Arabidopsis thaliana spaceflight omics datasets, with emphasis on:

- light signaling
- circadian regulation
- carbohydrate signaling
- miR156/SPL regulatory network
- developmental phase transitions

## Data source

NASA Open Science Data Repository (OSDR) / GeneLab.

## Current status

Project setup and dataset inventory.
